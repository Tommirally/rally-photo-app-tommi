# Rally Photos

One shareable event link where competitors find photos of their car from every
photographer. It starts with UK club rallying.

See **[PRODUCT_BRIEF.md](./PRODUCT_BRIEF.md)** for the product context, the domain
model and the milestone plan.

## Current state

This is a sample gallery that uses **fictional demo data** (`src/lib/demo-data.ts`).
Open `/events/demo-forest-stages-2026?car=32` to see car 32's photos from both
demo photographers.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # search logic tests
npm run build      # production build
```
